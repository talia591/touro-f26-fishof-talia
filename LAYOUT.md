# Layout Audit

| Where | What is being lined up | One direction or two? | Grid or flex? | Why |
|---|---|---|---|---|
| Page | Header, main content, and footer | Two | Grid | The main page areas use rows and columns. |
| Navigation | Three navigation links | One row | Flex | The links should stay in one evenly spaced row. |
| Homepage hero | Heading, description, and button | One column | Flex | The content is stacked vertically. |
| Product grid | Four product options | Two | Grid | The products appear in rows and columns. |
| Product cards | Product name and image | One column | Flex | Each card’s content is stacked vertically. |
| Classic Jelly details | Title, image, colors, description, price, and shipping | Two | Grid | The information is arranged across rows and columns. |
| Color choices | Pink, purple, and orange buttons | One row | Flex | The color buttons sit beside each other. |
| Cart item | Image, product information, quantity, and price | Two | Grid | The cart information uses both rows and columns. |
| Quantity controls | Minus, number, and plus buttons | One row | Flex | The controls should stay together in one row. |
| Cart summary | Prices, total, and checkout button | One column | Flex | The summary information is stacked vertically. |
| Confirmation message | Heading, message, and home link | One column | Flex | The confirmation content is stacked vertically. |
